KuraBuddy 無料トライアル 利用規約

施行日: 2026-11-25　／　この版の変更の効力が生じる日: 機能の提供開始日（サイトで告知）　／　最終更新: 2026-11-27　／　運営者: HKraft Labs（以下「運営者」）

この版で足した条項は、機能の提供開始日（サイトで告知）から適用します。対象は、業者機能（取引先の業者への発注の依頼）、発注の承認、Slack 通知に関する条項（第1条 5、第3条 6〜9、第4条 7〜10、第5条 5、第5条の2、第6条 6・7、第9条 6・7）です。機能ごとに提供の開始日が異なるときは、その機能の条項を、その機能の開始日から適用します。開始日は、その30日前までに、メールとサイト上で知らせます。

第1条（このサービスについて）

  1. KuraBuddy（以下「本サービス」）は、研究室の試薬・消耗品の在庫、入出庫、発注依頼を記録・管理する Web サービスです。
  2. この規約は、運営者が招待した研究室に無料で提供する試験提供（以下「トライアル」）に適用します。
  3. トライアルは招待制です。期間は、研究室ごとに招待の日から約 3 か月です。
  4. トライアルは無料です。稼働率などの保証（SLA）はありません。 止まったり、遅くなったり、機能が変わったりすることがあります。
  5. 本サービスには、研究室が、自分で選んだ取引先（試薬などの販売業者。以下「業者」）に、発注を依頼し、業者が状態（受注・納品・辞退など）とメモを入力できる機能があります（以下「業者機能」）。業者は、業者向けの利用規約に同意した、別の利用者で、日本国内の事業者に限ります。見積もりを依頼する機能は、まだありません。提供するときは、この規約を改めて知らせます。

第2条（利用できる人）

  1. 契約できるのは、研究室を運営する組織（大学、研究機関、企業の研究部門など。以下「契約組織」）です。個人が私的な目的で使うことはできません。
  2. 契約組織は、その構成員（研究室のメンバー）の行為について責任を負います。
  3. 招待を受けていない人、この規約に同意しない人は利用できません。
  4. 研究室の代表者が、契約組織を代表して規約に同意します。代表者は、同意する権限があること、また所属機関の規程で機関の承認が要る場合は、その承認を得ていることを、確かめてください。

第3条（アカウントと研究室のオーナーの責任）

  1. 利用者は、自分のメールアドレスとパスワードで登録します。正しい情報を登録し、パスワードを他人に教えないでください。
  2. 研究室には、権限の異なる役割（owner、admin、member）があります。研究室の owner は、次を行います。
    • メンバーの招待、権限の変更、メンバーを外すこと。
    • 研究室の記録の内容が正しいかを見ること。
    • 所属機関の規程（試薬・化学物質・研究データの管理）に従うこと。本サービスは、法令や機関の規程で求められる記録の代わりにはなりません。
  3. 本サービスの記録は、法令・機関の規程が求める試薬・毒物劇物などの管理簿の代わりにしないでください。
  4. アカウントが他人に使われた疑いがあるときは、すぐ support@hkraftlabs.com に連絡してください。
  5. 他の人の個人情報（招待先のメールアドレスなど）を入れるときは、必要な範囲にしてください。
  6. 業者機能について、研究室は次の責任を負います。
    • 取引先を選ぶこと、招待すること、「この相手で合っている」と確認して有効にすること、結びつきを外すこと。招待先のメールアドレスの打ち間違いや、なりすましに注意してください。
    • 発注の内容（品目、数量、希望納期、メモ）。
    • 納品先の内容と、連絡担当の方の同意。 納品先の連絡担当は、個人の名前でなく、担当の呼び名（例: ○○研 発注担当）と共用の電話でも構いません。個人の名前・電話番号を入れるときは、その方に、業者へ送られること（プライバシーポリシーの「7」）を伝え、同意を得てください。納品先を入力・変更するとき、取引先を有効にするときに、画面でこの確認のチェックを求め、確認したこと（誰が・いつ）を記録します。
    • 研究室のメンバーのだれが発注できるかを、owner が理解したうえで使うこと（発注は member も行えます）。
  7. 研究室は、発注のメモに、必要のない個人情報や機密情報を書かないでください。
  8. 発注の承認は、研究室の設定です。研究室の owner / admin が、設定の画面で有効にできます（初めは無効です）。有効の間は、承認された依頼だけを、発注できます。承認できるのは、owner / admin と、admin が承認者に指名した member です。自分の依頼を承認できるのは、owner / admin だけです。承認・却下したこと（誰が・いつ）と、その理由は、研究室の記録として残ります。却下の理由は、依頼した人、承認者、owner / admin だけに表示します（他の member、業者、お知らせメール、Slack には出しません）。承認の設定は、研究室の中の手続きの道具です。所属機関の購買・予算の規程で求められる承認の代わりにはなりません。
  9. Slack 通知は、研究室の設定です。研究室の owner / admin が、研究室自身の Slack の Incoming Webhook の URL を登録したときだけ、使えます。登録しない研究室には、何も送りません。Slack 通知について、研究室は次の責任を負います。
    • 自分の研究室の Slack のワークスペースで作った URL だけを登録し、URL を他の人に知られないよう管理すること。
    • 通知を受けるチャンネルと、その参加者を管理すること。送った内容は、そのチャンネルの参加者が読め、Slack の側に残ります。運営者は、Slack に送ったメッセージを、あとから消すことも、取り戻すこともできません。
    • 通知の文面には、人の名前（依頼した人・承認した人などの表示名）を入れません。ただし、品名と取引先の名前は、研究室が付けた名前のまま Slack（米国の事業者。サーバーが日本の外にあることがあります）に送られます。個人の名前（メンバーや、取引先の個人の氏名など）を、品名・取引先の名前として登録しないこと。 所属機関の規程で、外部のサービスに送る情報に承認が要る場合は、その承認を得ること。
    • Slack の利用条件を守ること。送った内容の Slack での扱いは、Slack の規約とプライバシーに関する定めによります。
    • 不要になったとき、または URL が漏れたおそれがあるときは、Slack の側で URL を無効にし、本サービスの設定を解除すること（owner / admin が、いつでも画面から解除できます）。

第4条（禁止すること）

次のことをしてはいけません。

  1. 法令や公序良俗に反すること。
  2. 他の研究室のデータを見る、変えるなど、権限のないアクセスをすること。そのための脆弱性の探索や攻撃をすること。ただし、見つけた不具合を運営者に知らせることは歓迎します。
  3. 過度な負荷をかけること（自動での大量アクセス、回数制限の回避）。
  4. 本サービスを複製・再販すること。契約組織の構成員以外の第三者に提供すること。
  5. 画像（OCR）に、試薬のラベルと関係のないもの（人の顔、書類、個人情報、機密情報など）を撮影して送ること。写ったものはすべて外部（Google）に送られます。
  6. 他人になりすますこと。虚偽の情報で登録すること。
  7. 業者に、迷惑な注文・見積もり依頼・メモを送ること（実際に購入する意思のない注文、大量の注文、嫌がらせなど）。
  8. 他人の住所・連絡先を、その人の同意なく納品先として入力すること。
  9. 業者の情報（担当者の名前、価格、メモなど）を、取引の目的以外に使うこと（他の目的での公開・第三者への提供を含む）。
  10. 他人の Slack のワークスペースに、その人の許可なく通知を送ること（他人の Webhook URL を、その人の許可なく登録することを含む）。
  11. その他、運営者が本サービスの運営に支障があると合理的に判断すること。

第5条（データの所有）

  1. 研究室が入力したデータ（製品、在庫、保管場所、入出庫、発注依頼など）の権利は、研究室（顧客）に残ります。運営者は取得しません。
  2. 運営者は、本サービスを提供・保守・改善・安全に保つために必要な範囲でだけ、データを扱います。研究室のデータを、他の目的（広告、第三者への販売など）には使いません。ただし、OCR を使うと、撮影した画像が Google に送られ、Google の無償枠の条件では、送った内容と応答が Google の製品の改善に使われ、Google の担当者が読むことがあります。Google は、無償枠に個人情報や機密情報を送らないよう求めています（プライバシーポリシー参照）。運営者が有償枠に切り替えたときは、Google の条件が変わるため、この規約とプライバシーポリシーを更新します。
  3. 運営者は、アクセス解析ツール（Google Analytics など）を使いません。
  4. 個人情報の扱いは、別に定める「プライバシーポリシー」によります。
  5. 研究室の owner / admin が Slack 通知を設定した場合、運営者は、発注に関する出来事（依頼が増えた、承認が必要になった、承認された、却下された、発注した、入荷した、取引先が受注・辞退・納品を記録した）を、研究室が指定した Slack のチャンネルへ送ります。送る内容は、システムが作る決まった文面だけで、品名、数量、取引先の名前（研究室が付けた名前）、アプリへのリンクです。人の名前（依頼した人・承認した人などの表示名）は、送りません。依頼のメモ、承認・却下・取消の理由、業者のメモ、納品先は、送りません。却下の通知は、「理由はアプリで確認してください」とだけ書きます。送る先のチャンネルと、その参加者の管理は、研究室の責任です（第3条 9）。詳しくはプライバシーポリシーを参照してください。

第5条の2（取引の当事者）

  1. 発注・見積もりによる売買その他の契約は、研究室と業者の間にだけ成立します。運営者は、その契約の当事者でも、代理人・媒介者・保証人でもありません。
  2. 価格、支払、請求、品質、数量、納期、納品、返品、保証、アフターサービスなど、研究室と業者の取引に関することは、運営者の関与の外にあります。本サービスを通して、運営者は、研究室と業者の間の金銭を取り扱いません。 取引に関する紛争は、研究室と業者が、直接解決してください。
  3. 運営者は、業者の身元、資格、許可、商品、信用を確認しません。画面に出る業者の組織名は、業者の自己申告です。取引先の選定は、研究室の責任で行ってください。
  4. 画面の「受注」「納品」「完了」「辞退」「取消」などの表示は、業者や研究室が入力した記録です。取引の成立・履行・解除を、運営者が確認・証明するものではありません。手動で「完了」にした記録も、研究室の記録であり、契約上の判断ではありません。
  5. 運営者は、研究室と業者の取引、業者が入力した内容、業者の行為（納品の遅れ、情報の目的外利用を含む）について、運営者に故意または重過失がある場合を除き、責任を負いません。 運営者の責任は、第9条に従います。
  6. 前項は、法令により制限できない責任には適用しません。
  7. 本サービスは、研究室と業者の間で、注文に付けるメモを中継することがあります。中継するかどうか、どの範囲を中継するかは、運営者の設定によります。中継しない設定の間は、メモは書いた側にだけ表示され、相手には表示されません。中継する場合も、運営者は、メモを通信の秘密として扱い（プライバシーポリシー参照）、メモの内容を事前に審査しません。発注の状態が変わったときに運営者が送るお知らせメールは、決まった文面です。メールに入るのは、研究室名、業者の名前、品名、数量とリンクだけで、メモ、断る理由、取消の理由、承認・却下の理由など、利用者が自由に書く文章は入れません。

第6条（データの書き出し）

  1. 研究室の画面から、製品・在庫・入出庫の記録を CSV で書き出せます。
  2. CSV に含まれない記録（履歴、操作の記録など）を含む全体の書き出しは、運営者が手作業で行います。support@hkraftlabs.com に請求してください。運営者は、書き出したファイルを暗号化し、受け取り方を登録のメールアドレスに送ります。復号のパスワードは、メールとは別の連絡手段でお知らせします。請求から 10 営業日以内を目標としますが、保証しません。
  3. トライアルが終わるときは、終了の 14 日前と、終了の前日に、運営者が研究室の owner にメールで知らせます。終了の日までに、各研究室で CSV を書き出してください。 請求があれば、運営者が全体を書き出します。
  4. 終了の日から 30 日間は、研究室は閲覧と書き出し（CSV、請求による全体の書き出し）だけができます。そのあと、研究室のデータを 90 日以内に削除します。この削除は、画面の機能ではなく、運営者が手作業で行います。
  5. バックアップは、削除の対象に入りません。プライバシーポリシーの保持期間が過ぎるまで残り、その後に自然に消えます。特定の研究室のデータだけを、バックアップから先に消すことはしません。
  6. 業者機能で業者に送った注文と、業者が入力した状態・メモ（相手側のメモは、運営者の設定により、あなたには表示されない場合があります）も、研究室の記録として、書き出しの対象です。業者との取引の記録がある研究室のデータを削除するときは、取引先の業者に事前に通知し、業者が自分の分を書き出す期間（通知から 30 日間）を置いてから削除します。この通知と書き出しの仕組みを提供するまでは、そのような研究室のデータの削除は、4 の期間を過ぎても行わないことがあります。
  7. 発注の承認の設定または Slack 通知を使った研究室のデータの削除は、運営者の削除の手順がまだ対応していないため、4 の期間を過ぎても行わないことがあります。Slack の Webhook URL は、書き出しの対象に入りません。

第7条（バックアップと、その限界）

  1. 運営者は、データを失わないことを最優先にしています。ただし、失わないことは保証できません。
  2. バックアップは次のとおりです（プライバシーポリシーも見てください）。
    • データベースは、毎日バックアップを取り、暗号化して米国の保管サービスにも置きます。
    • 毎日の分は 30 日、毎月の分は 12 か月、残します。
  3. 次の限界があります。
    • バックアップから戻すと、バックアップを取った時点の状態に戻ります。 その後の入力は失われることがあります（最大でほぼ 1 日分）。
    • バックアップから実際に復元できることは、本番の環境では、まだ確かめていません（開発用の環境での確認にとどまります）。
    • 運営者が復号の鍵を失うと、外部のバックアップは開けなくなります。鍵は 2 か所に保管しています。
    • 研究室の画面のデータは、研究室自身でも CSV で書き出して保存してください。
  4. 障害や事故でデータが失われたとき、運営者は復旧に努めますが、復旧の保証はしません。

第8条（一時停止・終了）

  1. 運営者は、次の場合、事前の通知なしに、アカウントまたは研究室の利用を一時的に止めることがあります。
    • 禁止事項に当たる、または当たる疑いがあるとき。
    • 不正アクセスや乗っ取りが疑われるとき。
    • 障害・保守・データを守るために必要なとき（書き込みを止めて閲覧だけにする場合を含む）。
  1. 運営者は、30 日前までに通知すれば、いつでもトライアルを終了できます。禁止事項の違反があるときは、通知を待たずに終了できます。
  2. 研究室は、いつでもトライアルをやめられます。やめる場合は support@hkraftlabs.com に知らせてください。
  3. 現在の仕組みでは、記録の削除に制限があります（プライバシーポリシー参照）。終了後のデータの扱いは第6条 4・5 のとおりです。

第9条（保証の否認と責任の制限）

  1. トライアルは 現状のまま 提供します。運営者は、正確さ、完全さ、特定の目的への適合性、中断のないこと、データの保全を保証しません。
  2. 運営者は、トライアルの利用または利用できなかったことで生じた損害について、運営者に故意または重過失がある場合を除き、責任を負いません。
  3. 前項の場合を除き、運営者が負う損害賠償の額は、次を上限とします。
    • 無料のトライアルの間は、0 円。
    • 有料のプランが始まったあとは、損害が生じた事由の前 12 か月に、運営者が顧客から受け取った利用料の総額。
    • 運営者に故意または重過失がある場合は、この上限を適用しません。
  4. 研究室は、重要な記録（法令や機関の規程で求められる管理簿を含む）を、本サービスだけに頼らないでください。
  5. 本条は、法令により制限できない責任には適用しません。
  6. 業者機能について、運営者は、業者が入力した内容の正確さ、業者の対応、メールの到達、通知の遅れ（お知らせメールの送信数には、1 日の上限があります。使い切ったときは、メールを送らずに画面に印を出します）、メモが相手に表示されること（相手に表示されない設定の場合があります）を保証しません。研究室は、重要な注文や連絡を、電話やメールなど、本サービス以外の方法でも確かめてください。
  7. Slack 通知について、運営者は、通知が届くこと、遅れずに届くこと、順番どおりに届くことを保証しません。送信が続けて失敗したとき、または Slack の側で URL が無効になったときは、運営者は Slack 連携を自動で止め、owner / admin にメールで知らせます（メールの 1 日の上限を使い切っているときは、メールを送れないことがあります）。研究室は、重要な発注を、Slack だけに頼らないでください。

第10条（規約の変更）

  1. 運営者は、次の場合に、この規約を変更することがあります。
    • 変更が、契約組織の一般の利益に適合するとき。
    • 変更が、契約の目的に反せず、変更の必要性、変更後の内容の相当性、この条で変更することがある旨と内容を定めていること、その他の事情に照らして、合理的なとき。
  2. 変更するときは、変更すること、変更後の内容、効力が生じる日を、メールとサイト上で、効力が生じる日より前に知らせます。重要な変更は、効力が生じる日の 30 日前までに知らせます。軽微な変更も、効力が生じる日の少なくとも 7 日前までに、サイトに掲載して知らせます。
