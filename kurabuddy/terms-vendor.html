KuraBuddy 業者（ベンダー）向け 利用規約

施行日: 機能の提供開始日（サイトで告知）　／　最終更新: 2026-11-27　／　運営者: HKraft Labs（以下「運営者」）

研究室の利用者の規約は、KuraBuddy 無料トライアル 利用規約です。個人情報の扱いは、プライバシーポリシーによります。

第1条（このサービスについて）

  1. KuraBuddy（以下「本サービス」）は、研究室の試薬・消耗品の在庫・発注依頼を管理する Web サービスです。本規約は、研究室から取引先として招待された、試薬・消耗品などの販売業者（以下「業者」）が、本サービスの業者機能（研究室から発注を受け、状態とメモを入力すること）を使うときに適用します。
  2. 業者の利用は無料です。運営者は、業者に利用料を請求しません。稼働率などの保証（SLA）はありません。 止まったり、遅くなったり、機能が変わったりすることがあります。
  3. 研究室は、別の規約（無料トライアル利用規約）に同意した、別の利用者です。

第2条（利用できる人・同意する権限）

  1. 利用できるのは、事業として業者の業務を行う、日本国内の法人・個人事業主（以下「業者組織」）と、その従業員など業者組織の業務に従事する人（以下「スタッフ」）です。個人が私的な目的で使うことはできません。日本の外の事業者は、利用できません。業者組織を作るとき、日本国内の事業者であることの確認を求めます。
  2. 業者組織を作る人（承諾をする人）は、業者組織を代表して本規約に同意する権限があることを確かめてください。権限がない場合は、同意しないでください。
  3. 業者組織は、そのスタッフの行為について責任を負います。
  4. 業者組織とスタッフは、反社会的勢力（暴力団、暴力団員、暴力団関係企業、総会屋その他これらに準ずる者）に該当せず、将来もこれらと関わらないことを表明し、保証します。違反があったときは、第9条により、通知なしに利用を止めます。
  5. 業者組織の名前、所在地、代表者などの情報は、正しく登録してください。画面に出る業者組織の名前は、業者組織の自己申告であり、運営者は確認しません。

第3条（運営者は取引の当事者ではありません）

  1. 発注による売買その他の契約は、研究室と業者の間にだけ成立します。運営者は、その契約の当事者でも、代理人・媒介者・保証人でもありません。
  2. 価格、支払、請求、品質、数量、納期、納品、返品、保証、アフターサービスなど、研究室との取引に関することは、業者が研究室と直接解決してください。本サービスを通して、運営者は、研究室と業者の間の金銭を取り扱いません。
  3. 運営者は、研究室の身元、信用、支払能力を確認しません。業者は、自己の責任で、取引するかどうかを判断してください。
  4. 画面の「受注」「納品」「辞退」「完了」「取消」などの表示は、研究室や業者が入力した記録です。取引の成立・履行・解除を、運営者が確認・証明するものではありません。
  5. 運営者は、業者と研究室の取引、研究室が入力した内容（納品先、メモ、数量）、研究室の行為について、運営者に故意または重過失がある場合を除き、責任を負いません。
  6. 研究室が Slack 通知を設定しているときは、受注・辞退・納品の記録のたびに、取引先として登録された業者の名前（研究室が付けた名前）と、注文の品名・数量が、研究室の Slack に通知されることがあります。業者のメモ、納品先、スタッフの名前・メールアドレスは、送られません。Slack の側での扱いは、研究室の責任です。

第4条（アカウントとスタッフの管理）

  1. スタッフは、自分のメールアドレスとパスワードで登録します。正しい情報を登録し、パスワードを他人に教えないでください。アカウントは共有しないでください。
  2. 業者組織には、権限の異なる役割（admin、staff）があります。業者組織の admin は、スタッフの招待・権限の変更・外すこと、スタッフが本規約と研究室のデータの取扱いルール（第6条）に従うことについて、責任を持ちます。 退職・異動したスタッフは、直ちに外してください。
  3. 業者組織の admin は、2 段階認証が必要です。設定するまで、業者の画面は使えません。
  4. アカウントが他人に使われた疑いがあるときは、すぐ support@hkraftlabs.com に連絡してください。
  5. スタッフの名前と、所属する業者組織の名前は、取引のある研究室に表示されます（注文の経過に、誰が・いつ・何をしたか）。スタッフは、登録・承諾のときにこのことを知らされます。スタッフのメールアドレスは、研究室には表示されません。スタッフの個人情報の扱いは、運営者のプライバシーポリシーによります。
  6. 業者のスタッフの名前を、本サービスの画面に出したくないときは、プライバシーポリシーの請求の方法（メール）で連絡してください。

第5条（禁止すること）

次のことをしてはいけません。

  1. 法令や公序良俗に反すること。
  2. 研究室へのスパム。 注文と関係のない営業、宣伝、勧誘のメッセージを、メモで研究室に送ること。メモは、その注文の連絡のためだけに使ってください。
  3. メモに、フィッシングなどの不正なリンクや、不審な URL を書くこと。
  4. 他の研究室・他の業者の情報を見る・変える、権限のないアクセスをすること。そのための脆弱性の探索や攻撃をすること。ただし、見つけた不具合を運営者に知らせることは歓迎します。
  5. 過度な負荷をかけること（自動での大量アクセス、回数制限の回避）。
  6. 本サービスを複製・再販すること。業者組織のスタッフ以外の第三者に使わせること。
  7. 他人になりすますこと。虚偽の情報で登録すること。虚偽の「受注」「納品」を入力すること。
  8. 第6条に違反して、研究室のデータを使うこと。
  9. その他、運営者が本サービスの運営に支障があると合理的に判断すること。

第6条（研究室のデータの取扱いと守秘）

  1. 業者が本サービスを通して受け取る、研究室の情報（研究室名、品目、数量、希望納期、表示された研究室のメモ、納品先（住所、建物・部屋、連絡担当、電話番号）など。以下「研究室のデータ」）は、その注文の履行（受注、納品、問い合わせ、請求のための確認）の目的だけに使います。
  2. 業者は、研究室のデータを、次のことに使いません。
    • 他の研究室や第三者への営業・宣伝・名簿づくり。
    • 第三者への提供・販売・開示（法令に基づく場合、研究室の同意がある場合、履行に必要な運送会社などへの委託の場合を除く）。
    • 分析・統計・サービスの改善など、履行以外の目的（個別の研究室を識別できない形にしたものを含め、研究室の同意がある場合を除く）。
  3. 業者は、研究室のデータを秘密として扱い、スタッフのうち履行に必要な人にだけ見せ、漏えい・滅失・毀損を防ぐための必要かつ適切な措置を講じます（アカウントの共有をしない、端末や紙に写したものを管理するなど）。
  4. 納品先に含まれる個人情報（連絡担当の名前・電話番号）は、納品の履行が終わり、問い合わせ対応に必要な期間が過ぎたら、遅滞なく、業者の側で削除（紙・メール・他のシステムに写したものを含む）します。 法令や会計上、取引の記録として保存が必要なもの（請求書、納品書など）は、その必要な範囲に限り、保存できます。ただし、保存する場合も、目的は第 1 項に限ります。
  5. 納品先は、その注文が進行中の間だけ、本サービスの画面に表示されます。業者が画面から見た内容を写した場合、その管理は、業者の責任です。
  6. 業者は、自らの責任で、個人情報の保護に関する法律を守ります。
  7. 研究室のデータの漏えいなどの事故が起きたときは、直ちに運営者（support@hkraftlabs.com）と、関係する研究室に連絡してください。
  8. 本条の義務は、本規約の終了後も続きます。

第7条（業者が入力する内容と、メモ）

  1. 業者が入力する内容（状態、納品予定日、メモ）は、業者の責任です。内容は、正確で、その注文の連絡に必要な範囲にしてください。
  2. 業者が入力した状態・納品予定日などは、取引のある研究室の記録として、研究室の画面に表示され、研究室が保存します。研究室が保存した内容の削除は、研究室の判断によります。
  3. 本サービスは、研究室と業者の間で、注文に付けるメモを中継することがあります。中継するかどうか、どの範囲を中継するかは、運営者の設定によります。中継しない設定の間は、メモは書いた側にだけ表示され、相手には表示されません。業者は、重要な連絡を、メモだけに頼らず、電話やメールなど、本サービス以外の方法でも行ってください。
  4. 運営者は、中継するメモを通信の秘密として扱い、内容を事前に審査しません。運営者は、障害の調査、不正の防止、取引の記録の確認のために必要な最小限の範囲と、法令に基づく場合を除き、メモの内容を見たり、利用や開示をしたりしません。
  5. 運営者が送るお知らせメールは、決まった文面で、メモや断る理由など業者・研究室が書いた文章は入れません。

第8条（データの保持・削除・書き出し）

  1. 研究室のデータを削除する場合で、その研究室に業者との取引の記録があるときは、運営者は、取引のある業者に事前に通知します（画面とメール）。業者は、通知から 30 日間、その研究室との自分の注文・経過を、CSV で書き出すことができます。書き出せるのは、業者に見えていた項目だけで、納品先と研究室のメンバーの情報は含まれません。この期間が過ぎたあと、研究室の削除により、その研究室との注文の記録は、業者の画面から見られなくなります。業者が書き出したかどうかにかかわらず、削除は行います。この期間に書き出してください。 この通知と書き出しの仕組みを提供するまでは、取引の記録がある研究室のデータの削除は行わないことがあります。
  2. 業者組織・スタッフのアカウントと、スタッフの情報は、業者が利用している間、残ります。運営者が本規約により利用を終えたあと、または請求があったときの消去は、プライバシーポリシーのとおり、できる範囲で行います。研究室との取引の記録の中のスタッフの名前は、研究室の記録として残る場合があります。
  3. バックアップは、削除の対象に入らず、プライバシーポリシーの期間が過ぎるまで残ります。
  4. 進行中の注文があるあいだは、研究室も業者も、結びつきを外すことはできません（先に辞退するか、完了させてください）。結びつきを外したあと、終わった注文は、読み取りだけで見られます（納品先は表示されません）。

第9条（一時停止・終了）

  1. 運営者は、次の場合、事前の通知なしに、スタッフ・業者組織・研究室との結びつきの利用を一時的に止めることがあります。
    • 禁止事項に当たる、または当たる疑いがあるとき（研究室からの苦情を含む）。
    • 不正アクセスや乗っ取りが疑われるとき。
    • 第 2 条 4 に違反するとき。
    • 障害・保守・データを守るために必要なとき。
  2. 運営者は、30 日前までに通知すれば、いつでも業者の利用を終了できます。禁止事項の違反があるときは、通知を待たずに終了できます。
  3. 業者は、いつでも利用をやめられます。業者組織の admin が、support@hkraftlabs.com に知らせてください。
  4. 終了したときも、進行中の注文は、研究室と業者が、本サービスの外で、直接連絡して解決してください。運営者は、進行中の注文の履行について、責任を負いません。
  5. 終了後も、第3条、第6条、第8条、第10条、第12条は有効です。

第10条（保証の否認と責任の制限）

  1. 本サービスは 現状のまま 提供します。運営者は、正確さ、完全さ、特定の目的への適合性、中断のないこと、データの保全、メールの到達を保証しません。
  2. 運営者は、業者の利用または利用できなかったことで生じた損害について、運営者に故意または重過失がある場合を除き、責任を負いません。
  3. 前項の場合を除き、運営者が負う損害賠償の額は、0 円を上限とします（業者の利用は無料のため）。運営者に故意または重過失がある場合は、この上限を適用しません。
  4. 業者は、重要な注文の記録を、本サービスだけに頼らず、自分の側でも保存してください。
  5. 本条は、法令により制限できない責任には適用しません。

第11条（規約の変更）

  1. 運営者は、次の場合に、本規約を変更することがあります。
    • 変更が、業者の一般の利益に適合するとき。
    • 変更が、本サービスの目的に反せず、変更の必要性、変更後の内容の相当性、この条で変更することがある旨と内容を定めていること、その他の事情に照らして、合理的なとき。
  2. 変更するときは、変更すること、変更後の内容、効力が生じる日を、メールとサイト上で、効力が生じる日より前に知らせます。重要な変更は、効力が生じる日の 30 日前までに知らせます。軽微な変更も、効力が生じる日の少なくとも 7 日前までに、サイトに掲載して知らせます。
  3. 変更後の規約は、効力が生じる日から、すべての業者に適用されます。変更に同意しない場合は、その日までに利用をやめてください。

第12条（準拠法・管轄）

  1. この規約は日本法に従います。
  2. 紛争が生じたときは、東京地方裁判所を第一審の専属的合意管轄裁判所とします。

  1. 業者は、運営者の書面（メール）による承諾なく、本規約に基づく地位や権利義務を、第三者に譲渡できません。
  2. 本規約のうち一部が無効でも、他の部分は有効です。
