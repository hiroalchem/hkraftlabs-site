1. 集める個人情報

KuraBuddy（無料トライアル）は、次を集めます。

種類内容集め方
アカウント名前、メールアドレス、パスワード（ハッシュ化したもの。元のパスワードは保存しません）、画像 URL（使う場合）登録のとき
所属どの研究室にいるか、役割、参加日招待・参加のとき

操作の記録誰が、いつ、何をしたか（入出庫、発注依頼、招待、メンバーの変更など）。発注依頼のメモなど、自由記述の文字利用中
ログインの記録セッションの IP アドレスと user agent、最後にログインした日時ログインのとき
回数制限IP アドレスとメールアドレスの組を、元に戻せない形（SHA-256）にした値、回数、期限ログイン・登録などのとき
OCR の画像と結果（OCR を有効にした場合のみ）試薬ラベルの写真、読み取り結果、撮影した人撮影したとき
  • 研究室が入れる製品名・在庫数量などは、通常は個人情報ではありませんが、メモなどに個人情報が入る場合があります。入れる内容は研究室が決めます。
  • 位置情報と広告用の識別子は集めません。アクセス解析ツール（Google Analytics など）は使いません。

2. 使う目的

  1. 本サービスの提供（ログイン、研究室の管理、在庫の記録、発注依頼）
  2. 本人確認、不正アクセス・乗っ取り・過度なアクセスの防止
  3. 誰がいつ何をしたかの記録（研究室の管理、誤りの訂正、障害の調査）
  4. メールの送信（登録の確認、パスワード再設定、招待、安全のための通知、トライアルの案内）
  5. 障害からの復旧のためのバックアップ
  6. 問い合わせへの対応
  7. （OCR を有効にした場合）ラベルの文字の読み取り

上の目的以外には使いません。この目的は、このポリシーで公表します。目的を変えるときは、変更前の目的と関連があると認められる範囲に限り、「9. 変更」の方法で知らせます。その範囲を超えて使うときは、あらかじめ同意をお願いします。

3. 預け先（委託先）と保管場所

本サービスは、次の事業者のサービスを使って個人情報を取り扱います。

事業者何のために保管・処理される場所渡る情報
Cloudflare, Inc.（米国）アプリの実行、データベース（D1）、画像の一時保存（R2）運営者は、データベースと画像の保存先に、アジア太平洋地域を指定しています。ただし Cloudflare は、この指定を「できるだけ」の配置としており、物理的な場所を保証していません（場所を保証する「ジュリスディクション」は設定していません。Cloudflare が用意している管轄は EU・FedRAMP・米国だけで、日本はありません。また、作成後には設定できません）。リクエストは、世界各地の Cloudflare のデータセンターで処理されることがあり、日本の外の国で処理される場合があります。本サービスの全データ
Backblaze, Inc.（米国）暗号化したバックアップの保管（B2、米国東部 us-east）米国データベース全体の写し（個人情報を含む）。運営者だけが持つ鍵で暗号化されています。Backblaze は中身を読めません。
Resend（Plus Five Five, Inc.、米国）メールの送信送信リージョンは東京（ap-northeast-1）を選んでいます。ただし Resend は、送信リージョンの選択にかかわらず、宛先・メールの内容・送信の記録を米国に保管すると説明しています。保管場所を変える設定はありません。宛先のメールアドレス、メールの本文（招待・登録・パスワード再設定のリンク、通知を含む）
Google LLC（Gemini API、米国）— OCR を有効にした場合のみラベル画像の文字の読み取り米国下の「OCR」参照

OCR（有効にした場合のみ）

  • OCR は、初期設定で有効です。運営者が無効にした間は、画像は外部に送られません。
  • 有効の場合、撮影したラベルの画像（JPEG・PNG・WebP、5MB まで）と、固定の指示文を Google の Gemini API に送り、読み取り結果（製品名、メーカー、型番、ロット、容量、使用期限）を受け取ります。名前やメールアドレスなど、利用者の情報は送りません。ただし、画像に写ったものはすべて送られます。 試薬のラベル以外（人の顔、書類など）を撮影しないでください。
  • 画像は、読み取りのあいだ Cloudflare R2 に一時保存し、完了または破棄したときに削除します（取り残しは 24 時間で削除する定期処理があります。実際の動作は本番で未確認）。読み取り結果は記録として残ります。
  • Google の無償枠では、送った内容（ラベルの画像）と応答が、Google の製品の改善に使われることがあり、Google の担当者が読むことがあります。Google 側の保持期間は、運営者は確認できていません。このため、ラベル以外は絶対に写さないでください。
  • 運営者は、のちに有償枠に切り替えることがあります。切り替えたときは、このポリシーを更新します。
  • Google の利用条件への参照: Google の Gemini API の追加利用条件と、無償枠・有償枠の扱いの説明を参照してください。条件は変わるため、公開の前と、条件が変わったときに確認して、このポリシーを直します。2026-11-24 の確認では、無償枠は上のとおり製品の改善と人の閲覧に使われ、Google は個人情報・機密情報を送らないよう求めています。有償枠（請求先アカウントを有効にした場合）では、改善には使われず、不正利用の検出などのために限られた期間だけ記録される、とされています（https://ai.google.dev/gemini-api/terms）。

日本の外での保管・処理

  • 上の事業者は米国の事業者で、個人情報は米国など日本の外で保管・処理されることがあります。運営者は、これらの事業者に個人情報の取扱いを委託しているものとして扱っています。
  • 米国の個人情報の保護に関する制度は、個人情報保護委員会が公表している外国の制度の情報を参照してください。各事業者は、それぞれの安全管理の措置を公表しています。
  • 外国にある事業者への提供について、個人情報保護法とガイドライン（外国にある第三者への提供編）が求める情報は、お求めがあれば、運営者が確認できる範囲で、遅滞なくお知らせします。この扱いが十分かどうかは、専門家の確認を受けていません。

4. 保持期間

対象期間
アカウント・研究室の所属・在庫や操作の記録契約（試験公開を含む）が続く間。トライアルが終わったあとは、30 日間は閲覧と書き出しだけを認め、そのあと研究室のデータを 90 日以内に削除します（利用規約 第6条）。バックアップは、下の期間が過ぎるまで残ります。
バックアップ原則として最長 13 か月
ログインの記録（セッションの IP アドレス・user agent）セッションには有効期限があります。期限が切れた記録を自動で消す処理は、いまはありません。ログアウトしたときなどに消えますが、残った記録は、アカウントが残る間、残ることがあります。バックアップには入りません。
回数制限の記録、メールの確認用の一時的な値期限が過ぎたあと、毎日の定期処理で削除します
OCR の画像読み取りの後に削除（遅くとも 2 日以内）

法律は、これらの期間を一律には定めていません。利用目的に必要なくなった個人データは、遅滞なく消すよう努めます（個人情報保護法 第22条）。上の期間は運営者の定めで、法定や研究機関の規程による保存の義務とは別です。

5. 消去の請求と、その限界

  • 個人情報の消去・利用停止は、メール（support@hkraftlabs.com）で請求してください。画面からはできません。運営者が内容を確認し、法令に従って対応します。
  • いまは、利用者が自分のアカウントを消す機能はありません。運営者も、アカウント（名前・メールアドレス・パスワード）を完全には削除できません。できるのは、研究室から外すこと、ログインを止めることなどで、できないことは、お返事でお知らせします。
  • 研究室の在庫・操作の記録は、研究室の記録として、追記専用で保存しています。記録の中の氏名などを消せない場合があります。製品を変えたときは、このポリシーを更新します。
  • バックアップには、消去前の情報が一定の期間（上の「保持期間」）残り、その期間が過ぎると消えます。
  • 請求に応じられない場合は、遅滞なく、その旨と理由をお知らせします。

6. 安全管理の措置

運営者は、取り扱う個人情報の漏えい・滅失・毀損を防ぐため、必要かつ適切な安全管理の措置（組織的・人的・物理的・技術的な措置）を講じます。具体的な内容は、安全のため公開しませんが、お問い合わせがあった場合は、支障のない範囲でお答えします。 漏えい等が起きたときは、法令に従い、個人情報保護委員会への報告と、本人への通知を行います。

7. 第三者への提供

法令に基づく場合を除き、本人の同意なく、上の委託先以外の第三者に個人情報を提供しません。法令に基づく場合など、法律が同意を要しないとしている場合（個人情報保護法 第27条）は、この限りではありません。委託先への提供と、事業の承継に伴う提供は、第三者への提供として扱いません。 同じ研究室の owner / admin / member は、研究室の画面で、メンバーの名前・メールアドレス・（owner / admin には）最後のログイン日時を見られます。

本人確認のため、登録したメールアドレスにお返事します。他の人の情報は開示しません。回答は、遅滞なく行います。目標は、請求から 14 日以内です（保証はしません）。開示は、電磁的記録（メールで送るファイル）で行います。手数料は、いただきません。開示しない場合（他人の権利を害するおそれなど）は、その旨を通知します。

9. 変更

重要な変更は、効力が生じる日の 30 日前までに、メールとサイト上で知らせます。軽微な変更は、サイトに掲載した時から効力が生じます。効力が生じる日のあとも使い続けた場合は、変更に同意したものとみなします。
